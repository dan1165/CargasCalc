# CargasCalc iOS Shortcut

`CargasCalc.shortcut` is an unsigned iOS Shortcut that asks for the four amounts and shows the full split, including the settle-up transfer lines when someone is over their share. It uses only built-in Shortcuts actions — no Scriptable, app, network, or stored state.

## Sign it

On a Mac with the Shortcuts CLI (macOS 12+):

```bash
cd shortcuts
plutil -convert binary1 CargasCalc.shortcut
shortcuts sign --mode anyone \
  --input CargasCalc.shortcut \
  --output CargasCalc-signed.shortcut
```

Then AirDrop or open `CargasCalc-signed.shortcut` on the iPhone and add it to Shortcuts.

iOS 15+ will not import the unsigned file; the signing step is required.

## What it asks

1. Cash in hand (RM)
2. Imran took (RM)
3. Bambang took (RM)
4. Danii took (RM)

It then shows total pot, cash in hand, taken early, each person's share and payout, and a **Settle up** block with exact payments when someone is over their share.

The split is cent-exact: the three shares use the same floor-with-remainder rule as `Sources/CargasCalcCore/Split.swift`, and an over-share debtor pays the people still owed in proportion to their payouts. With two people over, each pays the third their own overage.

## Rebuild

The plist is generated by `generate_shortcut.py`:

```bash
python3 generate_shortcut.py
```

It is deterministic apart from regenerated action UUIDs.

## Verification

The plist structure, action references, variable references, token-string ranges and conditional groups were validated in this workspace. The arithmetic and settle-up text were checked against the Swift and Scriptable versions for one-over, two-over, unequal-creditor, rounding and no-over cases. The shortcut has not been imported or run on an iPhone in this environment.
